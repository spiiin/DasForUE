# Типизированные аргументы по умолчанию

Генератор читает parameters[].default_text из IR v3 и добавляет типизированные
defaults в сигнатуры daScript. При пропуске аргумента его значение подставляется
на стороне скрипта, затем обычная обёртка выполняет маршаллинг и ProcessEvent.
Пустая строка default_text отличается от отсутствия default_text.

```das
let self = C_DasObjectFixture_5f019a81_from(ue_self_object())
verify(fixture_PolicyDefault(self) == 7)
verify(fixture_PolicyDefault(self, 23) == 23)
verify(fixture_DefaultScalars(self) == "defaults")
verify(fixture_DefaultScalars(self, 8, false, 2.0, 3.0lf, "override") == "override")
```

Это пример для тестового UDasObjectFixture. Полный исполняемый сценарий находится
в Plugins/DasForUE/Content/Das/Scripts/generated_defaults.das. generated_defaults_bad_type.das
намеренно не компилируется: optional аргумент сохраняет проверку типа при явной передаче.
Текущий выбор содержит 21 функцию, включая три функции для проверки defaults.

## Поддерживаемые значения

- int: десятичное число в диапазоне int32; минимальное значение выводится безопасным выражением.
- float/double: конечная десятичная запись, включая экспоненту; переполнение и
  уменьшение ненулевого значения до нуля при конвертации отклоняются.
  Double-литерал получает суффикс lf, без промежуточного преобразования во float.
- bool: только true/false.
- FString: текст metadata становится строковым значением; кавычки, обратные слеши
  и интерполяционные скобки экранируются. Текст не выполняется как код. NUL запрещён.
- FName: строковое значение через ue_name; длина проверяется в UTF-16 code units.
- enum: существующий символ enum или квалифицированный символ Type::Member.
  Числовое значение вместо символа не поддерживается.
- UObject: только пустая ссылка — None, nullptr или NULL; создаётся null нужного класса.

Defaults разрешены только для input-only параметров. После первого optional input
все последующие inputs должны иметь defaults. Return/out/inout не получают defaults.
Для struct, непустых объектных ссылок, произвольных C++ выражений и неподдерживаемых
записей генерация завершается ошибкой с alias функции и именем параметра.
Функция не пропускается молча и аргумент не становится обязательным без сообщения.
Предыдущий сгенерированный файл сохраняется, поскольку запись выполняется только
после успешной обработки всего IR. GenerateBindings.ps1 также сначала проверяет
оба staged артефакта, прежде чем обновить рабочие файлы.

## Точность и актуальность

Источник — CPP_Default_* из Unreal reflection, а не исходный C++ текст.
На текущем UE 5.8.3 UHT записывает default double 1.23456789012345 как 1.234568.
Скрипт получает именно отражённое значение 1.234568; генератор не может восстановить
отброшенную точность. Проверка DefaultWeight отдельно подтверждает, что явно
переданное 1.23456789012345lf проходит без дополнительного округления до float.

Изменение default_text меняет сгенерированную сигнатуру. После изменения metadata
нужна регенерация; GenerateBindings.ps1 -Check обнаруживает устаревший IR/код.
Runtime signature guard проверяет форму UFunction, но не сравнивает defaults:
editor metadata не гарантируется в packaged runtime. Ошибки компиляции/исполнения
по-прежнему обрабатываются существующим механизмом контекстов.

Category/DisplayName/ToolTip и прочие описательные metadata остаются описанием:
они не меняют исполнение. IR v3 не изменён структурно, но default_text теперь имеет
значение для генерации, а не только для документации.

Следующий срез: TArray поддерживаемых значений и правила владения при маршаллинге.
Объектные поля структур, AOT, DSL авторских классов и его hot reload остаются в плане.
Синтаксис DSL этим этапом не определяется.
